# Versão em Python (arquivada)

Primeira versão do Otimizador de Demanda (1.x), em Python + Streamlit. **Não é mais mantida**:
fica guardada só para consulta. O programa em uso é o app da pasta `web/`.

Ainda funciona, se precisar:

```
cd versao-python
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

O pacote portátil para Windows pode ser gerado com
`powershell -ExecutionPolicy Bypass -File empacotar.ps1` (dentro desta pasta).
A publicação automática desse pacote no GitHub foi desligada na versão 2.0.0.
